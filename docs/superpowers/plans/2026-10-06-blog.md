# duboc.github.io Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the 13-essay series *The Future of Software* as a bilingual (EN/PT toggle) Jekyll blog at `https://duboc.github.io/`.

**Architecture:** A stdlib Python exporter turns vault notes into a Jekyll collection (`_essays/`). Native GitHub Pages builds the site from `master` with hand-written layouts, one stylesheet and an inline toggle script. Verification is pytest for the exporter plus a live URL check after the Pages build.

**Tech Stack:** Python 3 (stdlib) + uv + pytest · Jekyll (GitHub Pages native) · Liquid · plain CSS/JS · just · gh

**Spec:** `docs/superpowers/specs/2026-10-06-blog-design.md`

## Global Constraints

- Repo `duboc/duboc.github.io`, branch `master`, Pages source `/`. No GitHub Actions.
- Commits only as `Anderson Duboc <andersonduboc@gmail.com>` (repo-local config already set). No AI trailers.
- No personal paths in the repo: vault location only via `NOTAS_VAULT` env var.
- Plugins limited to `jekyll-feed`, `jekyll-seo-tag`. No remote theme, web fonts, images, analytics or external requests.
- Site title `Anderson Duboc`. Tagline EN `Thinking out loud about software, AI, and the people who build it.` / PT `Pensando em voz alta sobre software, IA e as pessoas que constroem.`
- Footer: `© Anderson Duboc · Views are my own.` + GitHub (`https://github.com/duboc`) + RSS (`/feed.xml`).
- Essay URLs `/essays/<slug>/`; series hub `/the-future-of-software/`.
- Only the `## 🇺🇸` and `## 🇧🇷` sections of a vault essay are ever published.

## Review Focus

1. Titles/hooks containing `"`, `:` or `?` (e.g. *Good Code for Whom?*) must not break YAML front matter → Task 1 test `test_render_escapes_yaml`.
2. Renaming an essay in the vault must not leave a stale page live → Task 1 test `test_export_removes_stale_generated_files` (files without `generated: true` are kept).
3. Browsers where `localStorage` throws (Safari private mode) must still toggle → Task 2: wrap storage access in `try/catch`; verified manually in Task 3.
4. Readers without JS see both languages (never a blank page) → Task 2 CSS hides languages only under `html.js`; Task 3 `just check` asserts both `lang="en"` and `lang="pt-BR"` in served HTML.
5. NFD filenames from macOS must still match/slug correctly → Task 1 test `test_parse_normalizes_nfc`.

### Task 1: Vault exporter (TDD) + harness

**Files:**

**Interfaces:**
- Produces:
  - `SERIES: dict[str, str] = {"The Future of Software": "the-future-of-software"}`
  - `class ExportError(ValueError)`
  - `@dataclass(frozen=True) class Essay: slug: str; title_en: str; title_pt: str; body_en: str; body_pt: str; description: str; description_pt: str; date: str; series: str; part: int; order: int`
  - `slugify(title: str) -> str` — lowercase ASCII (strip accents via NFKD), non-alnum runs → `-`, trimmed.
  - `parse_essay(text: str) -> Essay` — NFC-normalizes first; frontmatter keys `date added`, `series`, `part` (`Parte <ROMAN> — …` → int 1–5), `order`; slug from EN title; description = first non-empty paragraph of each body.
  - `render_essay(e: Essay) -> str` — front matter (strings via `json.dumps`, `ensure_ascii=False`) with keys `layout: essay`, `generated: true`, `permalink` (`"/essays/<slug>/"`), `title` (= EN), `title_en`, `title_pt`, `description`, `description_pt`, `date`, `series`, `part`, `order`; then `<section lang="en" markdown="1">` / `<section lang="pt-BR" markdown="1">` blocks.
  - `export(folders: list[Path], out_dir: Path) -> list[Path]` — reads `✍️ *.md` (NFC-compared glob; skips `🗂️` hub), deletes existing `out_dir/*.md` containing `generated: true`, writes `out_dir/{order:02d}-{slug}.md`, returns written paths sorted.
  - CLI: `uv run scripts/export_from_vault.py --out _essays <folder>...` → exit 0, prints count; `ExportError` → message on stderr, exit 1.
  - Justfile: `quick` = `uv run --with pytest pytest -q tests/`; `export` = runs CLI with `"$NOTAS_VAULT/30_ATLAS/essays/the-future-of-software"` (fails if `NOTAS_VAULT` unset); `check` = `scripts/check_live.sh` (Task 3).

Fixture: a `SAMPLE` string in the test file mirroring a real vault note (frontmatter with `series: The Future of Software`, `part: Parte II — Ofício`, `order: 8`, `date added: 2026-09-25`; the `> Série: [[…]]` line; `## 🇺🇸 Good Code for Whom?` with two paragraphs, one containing `[[Some Note|alias]]`; `## 🇧🇷 Código Bom Para Quem?`; then `## 🌱 Texto-Semente Original` with a quote).

```python
def test_slugify():
    assert slugify("Good Code for Whom?") == "good-code-for-whom"
    assert slugify("Fire, Not Engine") == "fire-not-engine"
    assert slugify("Código Bom") == "codigo-bom"

def test_parse_sections_and_metadata():
    e = parse_essay(SAMPLE)
    assert (e.title_en, e.title_pt) == ("Good Code for Whom?", "Código Bom Para Quem?")
    assert (e.series, e.part, e.order, e.date) == ("the-future-of-software", 2, 8, "2026-09-25")
    assert e.slug == "good-code-for-whom"
    assert e.description == "<first EN paragraph of SAMPLE>"

def test_parse_drops_vault_only_content():
    e = parse_essay(SAMPLE)
    for body in (e.body_en, e.body_pt):
        assert "Série" not in body and "Texto-Semente" not in body
        assert "[[" not in body and "---" not in body
    assert "alias" in e.body_en and "Some Note" not in e.body_en

def test_parse_normalizes_nfc():
    e = parse_essay(unicodedata.normalize("NFD", SAMPLE))
    assert e.title_pt == unicodedata.normalize("NFC", "Código Bom Para Quem?")

def test_parse_missing_language_fails():
    with pytest.raises(ExportError, match="🇧🇷"):
        parse_essay(SAMPLE.split("## 🇧🇷")[0])

def test_parse_unknown_series_fails():
    with pytest.raises(ExportError, match="series"):
        parse_essay(SAMPLE.replace("The Future of Software", "Other"))

def test_render_escapes_yaml():
    out = render_essay(replace(parse_essay(SAMPLE), title_en='Say "hi": now?'))
    assert 'title_en: "Say \\"hi\\": now?"' in out
    assert 'permalink: "/essays/good-code-for-whom/"' in out
    assert '<section lang="en" markdown="1">' in out and '<section lang="pt-BR" markdown="1">' in out

def test_export_writes_and_is_idempotent(tmp_path):  # write SAMPLE into src as "✍️ 08 — Good Code for Whom.md" plus a "🗂️ Hub.md"
    first = export([src], out); content = first[0].read_text()
    second = export([src], out)
    assert [p.name for p in first] == ["08-good-code-for-whom.md"] == [p.name for p in second]
    assert second[0].read_text() == content

def test_export_removes_stale_generated_files(tmp_path):
    (out / "99-old.md").write_text("---\ngenerated: true\n---\n")
    (out / "manual.md").write_text("---\ntitle: keep\n---\n")
    export([src], out)
    assert not (out / "99-old.md").exists() and (out / "manual.md").exists()
```
