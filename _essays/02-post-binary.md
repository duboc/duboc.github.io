<section lang="en" markdown="1">

Eighty years of deterministic computers taught us the wrong lesson.

We learned how computers have worked and mistook it for how computers must work. Same input, same output, every time, instructions spelled out to the last flag. Tokens break that assumption. A computer that reasons in probabilities is not a worse calculator. It is a new kind of machine, and everything will be rebuilt on top of it.

Developer tooling feels it first. Shells, editors, CLI flags, the jq incantation you copy from a gist every six months: much of it will be washed away by tokens, at least for humans. Knowing flags by heart will look as arcane as writing everything as a Perl one-liner. That hurts to write for anyone who loves the terminal.

Interfaces go next. A lot of UI exists because software could not understand what you wanted. Menus, settings screens, dashboards, filters: a human-accessible API to a dumb machine. When the machine understands intent and answers faster than you can blink, most of that scaffolding becomes optional. Interfaces get generated on the fly, shaped to the question, gone when the answer lands.

Determinism was never natural. It was a fragile construct, held together by generations of electrical and process engineers so software could pretend to be mathematics. It survives as a foundation, thinner than we assumed, beneath a layer that finally speaks human.

Welcome to the post-binary era.

</section>

<section lang="pt-BR" markdown="1">

Oitenta anos de computadores determinísticos nos ensinaram a lição errada.

Aprendemos como os computadores funcionaram e confundimos isso com como os computadores precisam funcionar. Mesma entrada, mesma saída, sempre, instruções escritas até a última flag. Tokens quebram essa premissa. Um computador que raciocina em probabilidades não é uma calculadora pior. É um novo tipo de máquina, e tudo vai ser reconstruído em cima dele.

As ferramentas de desenvolvimento sentem primeiro. Shells, editores, flags de CLI, aquele comando de jq que você copia de um gist a cada seis meses: boa parte disso vai ser levada pelos tokens, pelo menos para humanos. Saber flags de cor vai parecer tão arcano quanto escrever tudo como one-liner em Perl. Dói escrever isso para quem ama o terminal.

As interfaces vêm em seguida. Muita UI existe porque o software não entendia o que você queria. Menus, telas de configuração, dashboards, filtros: uma API acessível a humanos para uma máquina burra. Quando a máquina entende a intenção e responde mais rápido do que um piscar, quase toda essa muleta vira opcional. Interfaces passam a ser geradas na hora, moldadas à pergunta, desaparecendo quando a resposta chega.

O determinismo nunca foi natural. Foi uma construção frágil, sustentada por gerações de engenheiros elétricos e de processo para que o software pudesse fingir ser matemática. Ele sobrevive como fundação, mais fina do que imaginávamos, embaixo de uma camada que finalmente fala a nossa língua.

Bem-vindo à era pós-binária.

</section>
