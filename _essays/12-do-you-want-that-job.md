<section lang="en" markdown="1">

Somewhere today, a developer is happily maintaining classic ASP.

That will stay true. Transitions like this take a generation. The new software will not replace the old overnight. It will surround it, then outgrow it, then quietly retire it, while pieces keep running in basements for decades. Ten years from now, people will still be paid to write code by hand. Some will be very good at it. Some will even enjoy it.

The question is not whether that job will exist. It is whether you want it.

Everything around it is moving. Code review is migrating from diffs to systems. Good code is being redefined for a new reader. The triad is folding into single people with three lenses. Tokens are becoming the computer, and interfaces are learning to disappear. The craft of building software, deciding what matters and for whom, has never been more valuable, and it is increasingly the only craft left.

Standing still is a choice, and a legitimate one. It is also a choice with a known ending: a smaller room, older tools, fewer people who remember why things were built that way.

The alternative is uncomfortable, unfinished and wide open, which is exactly what the early days always feel like.

Pick your decade.

</section>

<section lang="pt-BR" markdown="1">

Em algum lugar, hoje, um desenvolvedor mantém ASP clássico e está feliz.

Isso vai continuar verdade. Transições assim levam uma geração. O software novo não vai substituir o antigo da noite para o dia. Vai cercá-lo, depois superá-lo, depois aposentá-lo em silêncio, enquanto pedaços seguem rodando em porões por décadas. Daqui a dez anos, ainda vai ter gente paga para escrever código à mão. Algumas serão muito boas nisso. Algumas vão até gostar.

A pergunta não é se esse emprego vai existir. É se você quer esse emprego.

Tudo em volta está se movendo. O code review está migrando do diff para o sistema. Código bom está sendo redefinido para um novo leitor. A tríade está se dobrando em pessoas únicas com três lentes. Tokens estão virando o computador, e as interfaces estão aprendendo a desaparecer. O ofício de construir software, decidir o que importa e para quem, nunca valeu tanto, e cada vez mais é o único ofício que sobra.

Ficar parado é uma escolha, e uma escolha legítima. Também é uma escolha com final conhecido: uma sala menor, ferramentas mais velhas, menos gente lembrando por que as coisas foram construídas daquele jeito.

A alternativa é desconfortável, inacabada e escancarada, exatamente como o começo de tudo sempre parece.

Escolha a sua década.

</section>
